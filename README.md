
# SentinelMCP

SentinelMCP is a Python-based cybersecurity investigation server built using the Model Context Protocol (MCP) and FastMCP.

The project provides tools for analyzing authentication events, reading structured security logs, and detecting suspicious login activity.

Its initial detection capability identifies potential brute-force attacks when five or more failed login attempts occur within five minutes from the same username and source IP address.

Project Status: Active Development


## Available MCP Tools

### 1. analyze_login
Analyzes an individual authentication attempt and returns a risk level and finding based on whether the login succeeded or failed.

### 2. read_login_logs
Reads synthetic authentication events from a local JSON file and returns the total number of events and their details.

### 3. detect_brute_force
Analyzes failed authentication attempts grouped by username and source IP address.

Generates a potential brute-force finding when five or more failed attempts occur within a five-minute window.


## Technology Stack

- Python 3.11
- FastMCP 4.1.4
- Model Context Protocol (MCP)
- JSON authentication logs
- MCP Inspector for development and testing
- Git and GitHub for version control
- Visual Studio Code



## Installation

Clone the repository to your local machine:

```powershell 
git clone https://github.com/billythebean/SentinelMCP.git
```

Navigate into the project folder:

```powershell
cd SentinelMCP
```

Create a Python virtual environment:

```powershell
python -m venv .venv
```

Activate the virtual environment in Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install FastMCP:

```powershell
python -m pip install fastmcp==4.1.4
```

## Running SentinelMCP

Launch the MCP Inspector to test the server's tools:

```powershell
fastmcp dev inspector server.py
```

The Inspector provides a browser-based interface for connecting to SentinelMCP, viewing available tools, executing them, and examining their results.


## Example Detection Result

The following result was generated by SentinelMCP using synthetic authentication logs.

```json
{
  "total_findings": 1,
  "findings": [
    {
      "username": "jsmith",
      "source_ip": "192.0.2.10",
      "failed_attempts": 5,
      "time_window": "2026-10-27T08:59:00+00:00 to 2026-10-27T09:04:00+00:00",
      "finding": "Potential brute force attack detected."
    }
  ]
}
```

This detection identifies repeated failed authentication attempts from the same username and source IP address within a five-minute window. It indicates suspicious activity requiring further investigation, rather than confirming a successful compromise.
